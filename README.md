# Element Galaxy: a 3D interactive periodic table

A learning tool for curious middle-schoolers. All 118 elements float in space as glowing tiles, grouped into
family clusters. Tap any tile to open a field-guide panel with:

- name, symbol, atomic number, mass, family, group, period, and state at room temperature
- an animated diagram of the atom's electron shells, with a plain-language note about its outer electrons
- **combinations and reactions**: everyday compounds (e.g. Na + Cl → NaCl, table salt). Tap the other element in a reaction to fly to it.
- facts and everyday uses

Other features: search by name, symbol or number (press `/`); **Surprise me** for a random element;
click a family in the legend to light it up; switch between **Galaxy** (family clusters) and **Table** (classic layout);
arrow keys step through the elements while a panel is open; works with touch (drag to orbit, pinch to zoom).

## Run it

Open `index.html` in a modern browser. It's a single file with no build step. It loads Three.js r128 from a CDN
and fonts from Google Fonts, so it needs an internet connection.

## Reviewing or correcting the data

All data sits at the top of the `<script>` in `index.html`:

- `FAMILIES`: the colour scheme and a one-line description of each family
- `ELEMENTS`: one line per element (number, symbol, name, mass, family, period, group, shells, state)
- `DETAILS`: the about text, facts, uses and reactions for each element

`ELEMENTS` is generated by `tools/gen_elements.py`, which checks that every element's shell counts add up to its atomic number and
that group/period positions match the standard table. To change an element, edit the list in that script, run
`python3 tools/gen_elements.py`, and paste the output between `const ELEMENTS = [` and `];`.

Notes on the chemistry choices:

- Families follow the common school colour-coding, plus a **post-transition metals** group (Al, Ga, In, Sn, Tl, Pb, Bi, Po and the superheavy 113–116).
- Electron shells use the real ground-state configurations, including exceptions such as Cr (2, 8, 13, 1), Cu (2, 8, 18, 1) and Pd (2, 8, 18, 18).
- For elements 104–118, the shells and family are predictions; the app labels them that way.
- Masses in [brackets] are the mass number of the longest-lived isotope, for elements with no stable form.
